## 一、形态（同一套 moc3 就能变 3 档 + 另一套 Q 版）

长身模型里 `Clothes2` 这一个参数直接把整只缩放，exp3 把它做成了三个表情：

| 形态 | 触发方式 | 参数 | 视觉 |
|---|---|---|---|
| 长身（默认） | `默认体型.exp3.json` | `Clothes2 = 0` | 全身比，最高 |
| 半身（体型1） | `体型1.exp3.json` | `Clothes2 = 0.4` | 约 60% 高，站姿变小 |
| 豆丁（体型2） | `体型2.exp3.json` | `Clothes2 = 1` | 约 40% 高，Q 版比例、接近玩偶 |
| Q 版独立模型 | 另一套 `大肥鱼.moc3` | — | 独立模型：138 参数 / 108 drawable / 6 动作 / 14 表情 |

实测对照图：`_probe/grid-forms.png`（body0 / body04 / body1 三档同框）。
⚠ 三档是**同一模型的缩放**，不是三套网格：所以动作、物理、表情三档通用，切换只需 0.2s 渐变；但 `Clothes2` 在物理里同时是「尾巴」「前发Y」的输入，体型一变尾巴会跟着甩一下，切换时最好给 0.3s 缓冲。

## 五、动画（motion3，8 个 —— 素材里**只有**这 8 个）

| # | 文件 | 时长 | 循环 | 动什么 | 用途 |
|---|---|---|---|---|---|
| 1 | `IDLE` | 5.98s | 是 | 21 条曲线全在特效：`ShockL/R`、`Param11`、`SweatBurst1-4`、`Divider22`、`Param31/32`、`Param27-30`、`RCry/LCry`、`Startwinkle`、`Param55-58` | 待机呼吸特效（汗、泪、闪光、抖动），**不动姿态** |
| 2 | `默认手切举手` | 1.13s | 是 | `Movement2`、`Param62/59/60/61` | 抬左手（抚胸/害羞） |
| 3 | `举手切默认手` | 1.02s | 是 | 同上 | 放下左手 |
| 4 | `狗尾草切换出来` | 1.23s | 是 | `Movement1`、`Movement3`、右臂链 | 右手举狗尾草 |
| 5 | `狗尾草切回默认手` | 1.13s | 是 | 同上 | 收回 |
| 6 | `竖手指切出来动画` | 1.25s | 是 | `Movement3`、`Param40`、右臂链 | 右手竖食指 |
| 7 | `竖手指切回默认` | 1.25s | 是 | 同上 | 收回 |
| 8 | `脱捕` | 13.15s | 是 | 姿态 `AngleX/Y/Z`+`PositionX/Y/Z`、表情 `key3`/`key8`、嘴 `ParamMouthOpenY/Form`/`JawOpen`、24 条曲线 | **唯一的完整表演**（扭动/夸张表情/整体位移） |

## 七、工程现状（`assets/model/`）

- `motions/` 共 **21 个**：原素材 8 个（`idle`/`hand_up`/`hand_down`/`grass_out`/`grass_in`/`point_out`/`point_in`/`escape`）+ 自写 13 个（`nod`/`shake`/`tilt`/`bow`/`look_around`/`yawn`/`surprise`/`angry`/`sleepy`/`hop`/`peek`/`pout`/`pat_shy`）。
- `expressions/` 共 **23 个**：原素材全部 exp3，已改 ASCII 名并进 manifest。
- `model3.json` 分组：`Idle`(1)、`TapBody`(2)、`Prop`(2)、`Emote`(2)、`Special`(1)、`Gesture`(12)、`TapHead`(1)。
- 面板（`src/renderer/src/panel.ts`）是数据驱动的：manifest 里有什么就渲染什么，所以 21 个动作、23 个表情**都能从面板手动触发**。

**"动作少"的真正原因不是素材没接进来，而是行为层没有接线**（`src/renderer/src/behaviour.ts`）：

```ts
const IDLE_EMOTIONS = ['dizzy', 'sneer', 'squint', 'sweat', 'lean']   // 23 个表情里只用 5 个
// 待机：20–45s 随机闪一个表情
// 点头部 → heart + TapBody(hand_up)
// 点身体 → blush  + TapBody(hand_down)
```

也就是说：桌宠每 20–45 秒只换 5 个表情之一，点击只播 2 个手部动作，`Gesture` 那 12 个动作、9 个脸开关、9 个服装配件、3 个体型、3 个手部道具**全程没人调用**。要"动作多"，把行为层接上就够了，不需要再造素材。
