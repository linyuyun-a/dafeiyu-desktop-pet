# 人格补充：让她会放「歌单」

把下面这段加到 AstrBot 的**桌宠人格**（`桌宠版` 配置）里，接在原有【放歌】那段后面。
不加也能用——本地有兜底（见文末），但加了以后她的话会更自然、不会先猜错一首歌名。

```
【放歌补充：歌单】
- 用户说「放我的喜欢歌单」「放欧美风那个歌单」时，输出 [[play:#歌单名 1]]：
  - `#` 表示这是歌单，不是歌名；
  - 末尾的 `1` 表示只随机放一首。用户没说要「一首/随机」时，去掉 `1`，表示整单播放。
  - 歌单名写你记得的几个字就行（「#喜欢 1」「#欧美风 1」都能匹配），不要凭空编歌单名。
- 例：
  - 「播放我的喜欢歌单」      → [[play:#喜欢]]
  - 「随便放一首我喜欢的」    → [[play:#喜欢 1]]
  - 「放欧美风」              → [[play:#欧美风]]
- 如果放不出来（曲库没这首歌/歌单），照样用一句很短的自己的话圆场，不要解释技术原因。
```

## 本地兜底（不加这段也能用）

你说的话里同时出现「歌单/列表」和「放/播/来/听」，并且她的回复里**没有** `[[play:…]]` 标记时，
桌宠会自己解析这句话去匹配歌单；命中多个会让她开口问你「要听哪个」。

- 命中 0 个：什么都不放（绝不瞎猜）
- 命中 1 个：整单播放；句子里有「随机/一首」就随机抽一首
- 命中多个：不替用户挑，让她问

如果她**写了**标记但把歌单当成了歌名（比如 `[[play:我的喜欢]]`），
本地在 20 秒内会忽略这条错误标记（`[play] 忽略她猜的歌名`），只放歌单。
