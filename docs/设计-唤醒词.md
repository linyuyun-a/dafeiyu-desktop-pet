# 唤醒词（Keyword Spotting）实测与设计

2026-11-15 在本机（Windows 11、Python venv 内 `sherpa-onnx`）跑通并实测。

## 一、实测数字（先看这个）

| 指标 | 实测值 | 怎么测的 |
|---|---|---|
| 模型加载 | **1.0–1.1 s** | `KeywordSpotter(...)` 构造耗时 |
| 处理速度 | **RTF 0.022**（60 s 音频耗 1.31 s 算力） | 满速喂 60 s 静音 |
| **常驻 CPU** | **2.2–2.5%（单核）** | 每 100 ms 喂 0.1 s，跑 30 s，`process_time()/wall` |
| 唤醒延迟 | 整段喂入 14–19 ms 出结果；实时约 **150–300 ms** | 0.8 s 语音样本 |
| 模型体积 | 36 MB（int8 四件套；fp32 全量 60 MB） | 磁盘 |
| 内存 | 约 60–90 MB（进程） | 任务管理器估算 |

结论：**可以常驻**。2.5% 单核 ≈ 一个后台标签页；比"自建 VAD+ASR"（要跑 239 MB 的 SenseVoice）便宜一个数量级。

## 二、技术栈

- 引擎：`sherpa-onnx` 的 `KeywordSpotter`（**已在 TTS venv 里**，无需新依赖）
- 模型：`sherpa-onnx-kws-zipformer-wenetspeech-3.3M-2024-01-01`（中文、3.3M 参数、int8）
- 采集：`sounddevice`（同一 venv 已有），16 kHz / 单声道 / float32
- 关键词文件：`text2token` 生成（需要 `pypinyin`）

放置：`app/tts/kws-models/`（36 MB，**不进 git**）。

## 三、关键词怎么生成

```bash
# 1) 装 pypinyin（venv 内）
python -m pip install pypinyin

# 2) 写原文（# 后是阈值，@ 后是显示名）
printf '大肥鱼 #0.25 @大肥鱼\n鲸鸢 #0.25 @鲸鸢\n' > kw_raw.txt

# 3) 转 token
sherpa-onnx-cli text2token --tokens tokens.txt --tokens-type ppinyin \
  kw_raw.txt keywords_zh.txt
# 输出形如：d à f éi y ú #0.25 @大肥鱼
```

## 四、三个必须记住的坑

1. **重采样必须用 soxr**。用 `np.interp` 线性插值重采样后，`大肥鱼` **检测不到**；换 `soxr.resample(48k→16k)` 立刻命中。TTS 服务本来就用 soxr，直接复用。
2. **keywords 文件路径**要传给 `KeywordSpotter(keywords_file=...)`，且每行以 `@原文` 结尾；漏了 `@` 或阈值格式写错会静默不命中。
3. **`is_ready` 循环里取结果**：`while kw.is_ready(st): kw.decode_stream(st); r = kw.get_result(st)`；命中后要 `kw.reset_stream(st)`，否则同一句会连续触发。

## 五、接入方式（与"照搬 ChatGPT 方案"的区别）

不引 `sherpa-onnx-node`（原生模块，要 electron-rebuild + 跨 ABI，打包已 366 MB）。
改为 **Python 常驻 worker**：

```
app/tts/kws.py          新增：sounddevice 采麦 → KeywordSpotter → 命中打一行 JSON 到 stdout
app/main.mjs            改：ensureKws() 起子进程、读 stdout、命中后走 A 或 B
app/settings.html/js    改：开关、关键词、麦克风设备
app/tts/kws-models/     新增：模型（不进 git，README 写下载命令）
```

唤醒后两条路：

- **A（先做）**：只弹输入条（`shell.chatToggle(true)`），聊天窗里已有"点一下说话"的麦克风，最稳。
- **B（后做）**：直接录音 → 现有 `/asr` → `brainSay(text)`，免手。

## 六、防自唤醒与隐私

- TTS 播放/说话期间发 `kws:pause` 给 worker（或直接 `SIGSTOP`/协议暂停）——第一版最简单就是"她说话时暂停检测"。
- 默认关闭；开启时气泡说一次「我在听」，关闭时也说一次。
- 麦克风设备可在设置里选（`sounddevice.query_devices()` 列表）。

## 七、验收指标

| 项 | 目标 |
|---|---|
| 唤醒成功率（1–2 m，正常音量） | ≥ 95% |
| 误唤醒 | ≤ 1 次 / 小时（静音房间） |
| 唤醒延迟 | ≤ 500 ms |
| CPU | ≤ 3% 单核 |
| 内存 | ≤ 120 MB |
| 连续运行 | 8 小时不崩 |
