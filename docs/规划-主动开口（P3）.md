# P3 规划：让她主动开口（内容来自 AstrBot，不是本地模板）

> 现状（2026-11-10）：P2 已完成——云端 AstrBot 流式对话、`[[act:…]]` 语义标记驱动动作/表情、
> 气泡锁/打断/自动收起、`桌宠版` 配置文件 + `鲸鸢·桌宠` 副本人格。
> 舞台自带的「待机台词」仍是本地 `phrases.js` 的固定句子，**说来说去就那几句**。

## 1. 目标与边界

**要的**：她偶尔自己开口，内容是 AstrBot 现场生成的——带她的记忆、人格、时间和上下文，
不是抽模板。

**不要的**：

- 不要本地模板换个壳（那只是把"复读"包装得更像说话）；
- 不要打扰到人（正在打字、正在说话、深夜、她正演动作时都不该插话）；
- 不要污染主对话（主动发言不能把"用户说的话"顶掉，也不能让记忆里出现半句自问自答）。

## 2. 架构：本地管「什么时候」，AstrBot 管「说什么」

```
┌─────────────────────────── 客户端（Electron 主进程） ───────────────────────────┐
│  app/proactive.mjs（新）                                                          │
│    时钟/状态：空闲多久、现在几点、今天说了几句、上次开口多久前、是否勿扰          │
│    → 到点后调 brain:proactive                                                     │
│                                                                                   │
│  app/brain/astrbot.mjs                                                           │
│    沿用同一条 SSE 通道，只是 message 换成「导演提示」（见下），                      │
│    仍带 config_name=桌宠版、同一个 session_id                                     │
└───────────────────────────────────────────────────────────────────────────────────┘
                                   ↓ delta
              渲染层：和正常回话完全一样（气泡、打字机、[[act:…]]、自动收起）
```

**关键点**：主动说话不是新协议，就是"用一条旁白去戳她"。她能看到的上下文和平时一样，
所以她会记得昨天聊的书、记得现在是凌晨——这正是模板做不到的部分。

### 发给她的「导演提示」

用户消息位置发一段**括号旁白**（明确不是用户发言，避免她以为主人在说话）：

```
（旁白：此刻没有人跟你说话。现在 04:12，星期四。主人已经 6 分钟没碰过你了，
窗口开着，她可能还在。想开口就自然地说一两句——像突然想起一件事，或者忍不住吐槽，
不要问"有什么事吗/怎么了"，不要报"我在"。实在没什么想说的，只回 [[silent]]。）
```

- 返回 `[[silent]]`（或空）时，客户端**什么都不显示**，只记一条"她不想说"，避免硬凑。
- 旁白里的变量：时间、星期、空闲时长、今天互动次数、她上次开口说了什么（一句摘要）、
  当前是否在放音乐/全屏（有这些信号时再丰富，见 P3.3）。

## 3. 什么时候允许开口（门控，纯函数，可单测）

按顺序短路，任何一条不过就不开口：

| # | 条件 | 值（初版） |
|---|---|---|
| 1 | 用户手动关了「主动说话」 | `settings.proactive === false` → 永不说 |
| 2 | 勿扰时段 | 23:30–07:30 不说（跨午夜判断） |
| 3 | 正在交互 | 鼠标在角色上、气泡开着、她在演动作、正在流式回话 → 不说 |
| 4 | 刚说过 | 距上次开口 < 6 分钟 → 不说 |
| 5 | 今天说太多 | 当天 ≥ 12 句 → 不说 |
| 6 | 刚回过话 | 距上次对话结束 < 90s → 不说（她刚说完，追着说显得慌） |
| 7 | 空闲不足 | 无操作 < 90s → 不说（人可能正在看） |
| 8 | 随机闸门 | 到点后再掷一次 40% 的骰子，避免像定时播报 |

命中后进入**退避**：下一次最早 6 分钟，最长 20 分钟（随机），避免整点报时感。

### 三类触发（优先级从高到低）

1. **回来的瞬间**：系统空闲 ≥ 3 分钟后重新有操作 → 30s 内最多一句「你回来了」级别的开口；
2. **长时间安静**：连续空闲 6–15 分钟 → 每 8–15 分钟一次，一天不超过 12 次；
3. **事件余韵**：她刚被摸/被夸/被冷落之后（P3.3 再开）。

## 3.5 可行性实测（2026-11-10 04:07，真机）

用 `_probe/astr-proactive-probe.mjs` 直接打线上 AstrBot（`config_name=桌宠版`，
`username=desktop_pet`，`session_id=pet-proactive-a`），消息位置放上面那段旁白：

```
complete: "这个点还亮着屏幕……主人，你是打算把夜熬穿吗。[[act:tilt]]"
耗时 2219ms，事件序列 session_id → user_message_saved → run_started →
plain×N → agent_stats → complete → message_saved → end
```

⇒ **这条路是通的**：她没把旁白当"用户发言"回应（没有"有什么事吗"），
而是一句主动的、带情绪的、还自带动作标记的话。

**顺带发现（比原方案更好）**：`plain` 事件现在带 `chain_type: "reasoning"`，
说明推理片段是可以被**结构化识别**的。我们目前"等 complete 再打字机"的做法（首字 1.7s）
可以改成：流里丢掉 `chain_type === 'reasoning'` 的片段、其余直接当正文 —— 首字能回到 ~1.1s，
而且永远不用猜哪句是内心戏。这条独立于 P3，值得顺手做掉。

## 4. 不污染对话：三条硬规则

1. **不发用户消息进历史**：请求体加 `_skip_user_history: true`
   （openapi-v1.yaml:5292 的注释是「Internal WebUI flag for edit/regenerate flows」，
   即"这条不写进用户历史"）——**必须先实测**它是否真的跳过；
   若无效，退到方案 B：主动开口用独立 `session_id`（`pet-idle-<日期>`），
   代价是丢上下文，那就改为"每次主动开口时把最近 6 条对话摘要塞进旁白"。
2. **单独记账**：主动开口写 `stage-proactive.jsonl`（时间、提示、她回了什么、是否 silent），
   与 `stage-chat.jsonl` 分开，方便事后评估"有没有用"。
3. **不锁死对话框**：主动开口用 `owner: 'proactive'`，用户一打字立刻 `unlock` 并打断
   （`brain:interrupt`），不能出现"她自顾自说话，用户插不进去"。

## 5. 成本

一次主动开口 ≈ 一次完整请求（人格 7.5k 字 + 最近对话）。
按 6–15 分钟一次算，一天约 40–80 次请求；若嫌贵，加一档「轻量模式」：
旁白里只带最近 3 句 + 当前时间，不做长上下文（AstrBot 侧仍是原会话，成本主要在人格）。
设置里给开关 + 频率三档（少 / 正常 / 多 = 20–40min / 8–15min / 4–8min）。

## 6. 分阶段

| 阶段 | 内容 | 验收 |
|---|---|---|
| **P3.1** | `app/proactive.mjs` 触发骨架 + `brain:proactive` IPC + 右键「让她说一句」手动按钮 | 手动点一下，她真的说一句**不是模板**的话；`[[silent]]` 时不出气泡 |
| **P3.2** | 门控表 + 三档频率 + 勿扰 + 设置项是否持久化 + 静默标记 | 用假时钟跑单测：20 组场景该说/不该说全对；真机挂 30 分钟观察不扰人 |
| **P3.3** | 事件型开口：你回来 / 你切走 / 系统空闲 / 刚被摸（接 `regions` 的 feedback） | 每个事件都能触发一次，且不重复轰炸 |
| **P3.4** | 观察与调参：`stage-proactive.jsonl` 统计命中率、被无视率；按数据改阈值 | 一周数据，误扰 ≤ 每小时 1 次 |

## 7. 待定（需要你拍板）

1. **频率默认哪档**？（我建议"正常"：8–15 分钟一次，一天上限 12）
2. **她能不能主动"追问"**？（比如你半天没回她一句，她再说一句。我倾向：最多一次，且要隔 3 分钟）
3. **QQ 那边要不要同步主动**？（现在只有桌宠窗口会主动；QQ 侧的主动要动 `private_companion` 插件，属于另一件事）
4. **沉默权**：`[[silent]]` 时你希望完全没动静，还是让气泡闪一下"……"再消失？（我建议完全没动静）
