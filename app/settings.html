高级

窗口层级、鼠标穿透、开机自启。

穿透时角色区不可点，舞台里会浮出「恢复鼠标」；也可按 Ctrl+Alt+L 找回，Ctrl+Alt+Q 退出。

接你自己的智能体

桌宠本身不带大脑：语言来自一个 AstrBot（或任何兼容它的 HTTP 服务）。换人设、换记忆，都在那边改。

  1. 在跑 AstrBot 的机器上打开 WebUI → 设置 → OpenAPI，新建一个 API Key，权限至少勾 chat。
  2. 把地址和 Key 填进桌宠目录下的 brain.config.json： 
    {
  "brain": "astrbot",
  "astrbotUrl": "http://你的服务器:6185",
  "astrbotKey": "abk_xxxxxxxx",
  "astrbotConfig": "桌宠版"
}
  3. 重启桌宠。她会用这个 Key 调 /api/v1/chat，username 固定 desktop_pet，session_id 存在 _data/stage-chat-state.json —— 那就是她的"记忆槽"。
  4. 想让"大肥鱼"这个人设生效：在 AstrBot 里复制一份配置文件（用 WebUI 的「复制配置文件」，不要用 API 建），把人设写进去，再把它填到 astrbotConfig。

没有服务也能用：留空 Key 会自动回落到 mock（本地固定台词），气泡照常出现，只是不会真聊天。
